# 🥗 다이어트 SOS

다이어트할 때 실제로 겪는 **400가지 상황**(늦은 밤 배고픔, 가짜 배고픔, 먹어도 먹어도 배고픔, 정체기, 폭식, 회식, 명절…)과
각 상황의 **원인 → 해결법 → 근거 자료**를 정리한 웹 앱입니다.

👉 **앱 바로 열기:** https://charaing.github.io/diet-sos/

## 기능
- 20개 카테고리 × 20개 상황 = 400개
- 검색 (예: `야식`, `가짜 배고픔`, `정체기`, `회식`)
- "지금 이런가요?" 빠른 찾기 버튼
- ★ 저장하기 (브라우저에 저장), 🎲 랜덤 팁
- 각 해결법에 논문·가이드라인·책 출처 표시 (참고 문헌 70여 건)
- 휴대폰 홈 화면에 추가 가능, 다크 모드 지원

## 근거 자료
수면과 식욕(Spiegel 2004, Tasali 2022), 초가공식품(Hall 2019), 습관 형성(Lally 2010), 실행 의도(Gollwitzer 2006),
체중 유지(National Weight Control Registry), 당뇨예방프로그램(DPP 2002), 대한비만학회 비만 진료지침 2022,
WHO 당류·감미료 가이드라인, NICE 비만·섭식장애 가이드라인 등. 전체 목록은 앱 하단 "참고 문헌 전체 보기" 또는 `data/refs.js`.

## 데이터 구조
`data/d01.js` ~ `data/d10.js`: `[카테고리, 상황, 원인, [해결법…], [참고문헌 키…]]`
